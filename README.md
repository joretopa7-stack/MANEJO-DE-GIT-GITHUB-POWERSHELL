# 📌 Descripción

Esta guía contiene los conocimientos fundamentales y profesionales de **PowerShell** orientados al desarrollo de software, administración de sistemas y automatización de tareas.

El objetivo es comprender PowerShell como una herramienta profesional que permite interactuar con el sistema operativo, administrar recursos y mejorar la productividad mediante comandos y scripts.

---

# 🎯 Objetivo

Desarrollar habilidades para utilizar PowerShell como herramienta complementaria dentro del perfil de un desarrollador ADSO.

La guía busca aprender a:

- Trabajar con la terminal de forma profesional.
- Administrar archivos y recursos del sistema.
- Automatizar tareas repetitivas.
- Crear scripts para mejorar procesos.
- Gestionar entornos de desarrollo.
- Integrar herramientas utilizadas en proyectos de software.

---

# 🛠️ Herramienta principal

| Herramienta | Descripción |
|---|---|
| PowerShell | Shell de comandos y lenguaje de scripting de Microsoft |
| Terminal | Interfaz para interacción con el sistema |
| Scripts | Automatización de tareas mediante código |
