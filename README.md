# 📌 Descripción

Esta guía contiene los conocimientos fundamentales y profesionales de **Git y GitHub** necesarios para un desarrollador ADSO que busca desempeñarse en equipos reales de desarrollo de software.

El contenido está orientado a un nivel **Junior Competitivo**, enfocado en comprender no solamente los comandos, sino también los flujos de trabajo utilizados en la industria.

---

# 🎯 Objetivo

Aprender a utilizar Git y GitHub como herramientas profesionales para:

- Gestionar versiones del código.
- Organizar proyectos de software.
- Trabajar con ramas.
- Colaborar con otros desarrolladores.
- Mantener un historial limpio de cambios.
- Aplicar buenas prácticas de desarrollo.

---

# 🛠️ Herramientas utilizadas

| Herramienta | Descripción |
|---|---|
| Git | Sistema de control de versiones distribuido |
| GitHub | Plataforma para alojar y colaborar en proyectos |
| Terminal | Interacción con Git mediante comandos |
| Markdown | Creación de documentación técnica |

# 📖 Contenido de la guía

## Fundamentos

- ¿Qué es Git?
- ¿Qué es GitHub?
- Diferencias entre Git y GitHub.
- Conceptos de repositorios.
- Versiones y commits.

## Flujo de trabajo

- git init
- git clone
- git status
- git add
- git commit
- git push
- git pull
- git fetch

## Ramas

- Creación de ramas.
- Cambio entre ramas.
- Eliminación de ramas.
- Estrategias profesionales.
- Git Flow.

## Trabajo colaborativo

- Pull Requests.
- Code Review.
- Issues.
- Resolución de conflictos.
- Merge.

## Buenas prácticas

- Uso correcto de commits.
- Archivo .gitignore.
- Organización de repositorios.
- Creación de README profesionales.

## Conceptos avanzados

- Git Stash.
- Git Rebase.
- Git Tags.
- SSH.
- GitHub Actions básico.
